# Project agent guidance

Read `.specify/memory/constitution.md` and the active feature's recorded task and
validation state before implementation. Preserve existing ownership and review boundaries.

Every future implementation group or commit/push MUST update
`docs/implementation-changelog.md` with its relevant task status, every included file
and purpose, shared-system/integration effects, verification results, known errors,
limitations and unfinished work. Keep this record cumulative; distinguish implemented
work from verified behavior and actual reviewer agreement. Update it before committing
or pushing, and never invent acceptance or teammate sign-off.
