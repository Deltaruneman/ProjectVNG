# Emberline 무료 전투 효과 6개

Godot **4.7.2 안정판 / Compatibility 렌더러**용 2D 효과 원본입니다. 버전 1.0.0.

## 실행

1. ZIP을 새 폴더에 풉니다.
2. Godot에서 **project.godot**를 가져온 뒤 F5를 누릅니다.
3. 1~6 또는 Replay로 각 효과를 재생합니다. Space 또는 Fire로 투사체 → 잔상 → 피격 예제를 봅니다.
4. 색상·크기·속도·강도를 조절합니다. Light / Dark는 6개 카드의 배경과 대비 설정을 바꿉니다.

피격 불꽃, 충격파, 발광 투사체, 이동 잔상, 베기, 바닥 범위 효과가 들어 있습니다. 팔레트 3개는 같은 6개 효과의 설정입니다. PNG 스프라이트시트·음원·적 AI·충돌 판정은 포함하지 않습니다.

## 내 게임에 적용

**emberline 폴더 전체**를 내 프로젝트의 루트에 복사합니다. 경로는 **res://emberline/**이어야 합니다. 내 project.godot는 교체하지 않습니다. effects 내부 파일은 모두 유지하고, 예제 demo 폴더는 필요에 따라 제외할 수 있습니다.

emberline/effects/의 .tscn을 장면에 넣으면 자동 재생됩니다. 일회성 효과는 종료 후 자동으로 해제됩니다. 반복 효과는 **stop()**으로 종료합니다. 재사용하려면 종료 전에 **free_on_finish = false**로 설정하고 **play()**를 호출합니다.

- tint, accent: 색상. effect_scale: 크기. playback_speed: 재생 속도.
- light_surface: 밝은 배경에서 읽기 쉬운 진한 중심색.
- 원점은 중심입니다. area_burst만 바닥 접점입니다. 투사체의 앞쪽은 로컬 +X입니다.
- 잔상은 안정적인 월드 부모 아래에 따로 생성하고, 매 프레임 투사체의 global_position을 전달합니다. 피격 시 잔상을 stop()한 후 투사체를 제거하면 뒤에 남은 선이 자연스럽게 사라집니다.

정확한 코드 예제와 전체 설정은 README.md를 참고하세요. 원본 프로젝트 실행에는 Godot이 필요하며 별도 애드온·키·유료 의존성은 없습니다.

Windows의 Godot 4.7.2 / Compatibility / AMD Radeon에서 가져오기, 입력, 효과 수명, 100회 반복 정리, 밝고 어두운 배경 등을 확인했습니다. 다른 OS·Godot 버전·렌더러·모바일·웹은 미검증입니다.
