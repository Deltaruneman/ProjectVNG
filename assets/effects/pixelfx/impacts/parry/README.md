# Parry feedback export

Exported from the bundled pixelfx `impacts/parry` without modifying its source.
31 frames, 200 x 112, 30 fps, non-looping; pivot [100, 96]. Contact is at [100, 66].
The game plays at 1.5x speed, with nearest filtering and a 30 px vertical contact correction.

Regenerate from the library root:
`node tools/render.mjs impacts/parry --sheet --no-actor --out D:/VNG/ProjectVNG/assets/effects/pixelfx`
