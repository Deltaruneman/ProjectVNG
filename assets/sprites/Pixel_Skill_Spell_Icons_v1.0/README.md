# Pixel Skill & Spell Icons (32x32) v1.0
by reodesuxz - free for personal and commercial games.

48 pixel-art skill and spell icons: 8 elements (fire, ice, lightning, earth, wind, holy, dark, poison) x 6 types (orb, shard, nova, ward, strike, star).
32x32 px, framed square icons with top-left light shading.

## Files
- PNG/32x32/<element>/<name>.png and PNG/128x128_x4/ (nearest 4x)
- spritesheet.png (8 columns) + spritesheet.json, spritesheet_x4.png

## Import tips
Unity: Sprite, PPU 32, Filter Point, Compression None. Godot: Default Texture Filter Nearest. GameMaker: disable interpolation. Scale by whole numbers.
